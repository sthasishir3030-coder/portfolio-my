# Sishir Portfolio Website

A modern, responsive, full-stack portfolio website built for Sishir, highlighting academic achievements, STEM coursework (Class 12 NEB & IOE Entrance preparation), skills, and technical projects.

## Folder Structure

```
sishir-portfolio/
├── index.html          # Main HTML structure
├── css/
│   └── style.css       # Complete CSS styles (Glassmorphism theme)
├── js/
│   ├── server.js       # Simulated Express.js JavaScript Backend Engine
│   └── app.js          # Frontend DOM interaction & API routing script
└── README.md           # Documentation
```

## How to Run
1. Open the `sishir-portfolio` directory.
2. Double-click `index.html` or open it in any web browser.
